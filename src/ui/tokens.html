Ferro Monochrome Design Specification
Палитра и геометрические спецификации интерфейса wry GTK.
GTK3 + WebKit2GTK
Палитра фона #111111 (Tabs) / #1c1c1c (Toolbar) / #141414 (Viewport)
Разделители 1px solid #2a2a2a (Hairline)
Скругления (Радиусы) 0px (Вкладки, Окно) / 2px (Омнибокс, Кнопки)
Типографика Inter, System UI, JetBrains Mono
Вкладки Obsidian flush style, 1px разделители, без цветной полосы
Анимации 120-160ms cubic-bezier(0.2, 0, 0, 1)
Блокировщик рекламы adblock-rust (Brave) перехват сетевых запросов
Инъекции JS/CSS initialization_script + evaluate_script

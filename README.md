# Ferro Browser

Минималистичный, быстрый и кастомизируемый десктопный веб-браузер на **Rust** (`wry` + `WebKitGTK` + `GTK3`) для Linux (Wayland / X11).

## Ключевые возможности

- **Google Объектив (1:1 как в Chrome) и Боковая панель**:
  - По ПКМ на любом месте страницы (**«Найти с помощью Google Объектива»**) или по кнопке в адресной строке включается интерактивное выделение области со скруглёнными белыми уголками и подсветкой картинок.
  - По ПКМ на картинке (**«Найти картинку через Google Объектив»**) изображение отправляется напрямую в `lens.google.com/v3/upload` (работает даже для `blob:`, `data:` и защищённых от хотлинка картинок).
  - Изменяемая по ширине **Боковая панель** справа (`gtk::Paned`): результаты Google Объектива, **Закладки**, **История** и кнопка переноса в полноценную вкладку.
- **Многовкладочная и многооконная архитектура, Режим чтения и Медиа**:
  - **Вытягивание вкладки в отдельное окно (Tab Tear-Off, как в Chrome)** — потяните вкладку вниз или за пределы полосы вкладок (либо выберите **«Переместить вкладку в новое окно»** по ПКМ), и она мгновенно отделится в собственное окно без перезагрузки страницы и без прерывания видео/аудио.
  - Перетаскивание вкладок мышью (**Drag-and-Drop**), закрепление (**Pin Tab**), выключение звука (**Mute Tab**), выгрузка фоновых вкладок из ОЗУ (**Усыпить вкладку / Sleep Tab**) и «Закрыть вкладки справа».
  - **Режим чтения (`Alt + R`)** с выбором шрифта (`Sans` / `Serif`), кегля и темы бумаги (`Тёмная` / `Сепия` / `Светлая`).
  - **Картинка в картинке (PiP)**, сохранение чистого PNG-кадра из `<video>` в полном разрешении и управление скоростью воспроизведения прямо из ПКМ по видео.
  - Встроенный **QR-код страницы**, копирование чистых ссылок без UTM/трекеров, копирование ссылки на выделенный фрагмент (`#:~:text=`) и мгновенный всплывающий перевод выделенного текста.
- **Высокая производительность**:
  - Аппаратное GPU-ускорение (`HardwareAccelerationPolicy::Always`), кэш страниц `bfcache` (`enable_page_cache`), DNS-предвыборка и модель кэша `CacheModel::WebBrowser`.
  - Мгновенный старт за счёт кэширования скомпилированного `WebKitUserContentFilter` на диске и фоновой компиляции в отдельном потоке.
  - Точечное `O(1)` обновление вкладок без перестроения DOM и оптимизированный косметический фильтр `requestIdleCallback`.
- **Глобальная кастомизация (`ferro://settings`)**:
  - **Темы оформления**: Тёмная (Obsidian) и Светлая тема во всём интерфейсе.
  - **Акцентные цвета (Material You)**: готовые пресеты и произвольный HEX/Color Picker.
  - **Настройка скруглений (`0px`–`20px`)**: плавное изменение геометрии вкладок, омнибокса, кнопок, карточек и меню от строгих прямых углов до округлого стиля.
  - **Темы верхней панели (Firefox-style)**: Монохром, Карбон, Северное сияние, Закат, Кибернеон.
  - **Прозрачность интерфейса (Zen Glass)** и **кастомные обои** на новой вкладке (встроенная коллекция, URL или локальный файл, настройка Blur и Brightness).
- **Умный поиск и иконки сайтов**:
  - Переключатель поисковых систем с цветными иконками прямо в строке поиска и омнибоксе (**Google**, **DuckDuckGo**, **Яндекс**, **Bing**, **Brave Search**, **YouTube**, **GitHub**).
  - Автоматические иконки (favicons и векторные логотипы) на панели закладок, вкладках и плитках быстрого доступа `ferro://newtab`.
- **Кастомное контекстное меню (ПКМ в стиле Firefox)**:
  - Быстрая панель навигации (`Назад`, `Вперёд`, `Обновить`, `В закладки`), контекстные действия для ссылок, изображений, выделенного текста и полей ввода, сохранение страницы, снимок экрана (`PNG`), просмотр исходного кода (`Ctrl+U`) и WebKit DevTools (`Исследовать` / `F12`).
- **Встроенный блокировщик рекламы (uBlock / EasyList / RuAdList)**:
  - Нативный контент-фильтр `WebKitUserContentFilter` + сетевой движок `adblock` + косметическая фильтрация CSS/DOM.
- **Пароли, загрузки, история и импорт данных**:
  - Полноценный менеджер паролей (`ferro://passwords`): сохранение при редиректах форм, React/Vue-совместимое автозаполнение, встроенный выбор аккаунта и генератор паролей прямо в полях ввода, ручное добавление и редактирование, импорт/экспорт CSV (Chrome, Firefox, Bitwarden).
  - Менеджер загрузок (`ferro://downloads`, `Ctrl+J`) с живым прогрессом скачивания, открытием файла и переходом в папку.
  - Поиск на странице (`Ctrl+F`) через нативный `FindController` и печать / сохранение в PDF (`Ctrl+P`).
  - История просмотров (`ferro://history`) с поиском и автоматический импорт закладок/истории из сторонних браузеров.

## Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + T` | Новая вкладка |
| `Ctrl + N` | Новое окно |
| `Ctrl + W` | Закрыть текущую вкладку |
| `Ctrl + Shift + T` | Восстановить закрытую вкладку |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Следующая / предыдущая вкладка |
| `Ctrl + 1..9` | Переключиться на вкладку 1–9 |
| `Ctrl + F` | Найти текст на странице |
| `Alt + R` | Режим чтения (Reader Mode) |
| `Ctrl + J` | Менеджер загрузок (`ferro://downloads`) |
| `Ctrl + P` | Печать / Сохранить как PDF |
| `Ctrl + +` / `Ctrl + -` / `Ctrl + 0` | Масштаб страницы (+10% / -10% / Сброс) |
| `Ctrl + L` / `Alt + D` / `F6` | Фокус в адресную строку |
| `Ctrl + R` / `F5` | Обновить страницу |
| `Ctrl + D` | Добавить / удалить страницу из закладок |
| `Ctrl + Shift + B` | Показать / скрыть панель закладок |
| `Ctrl + H` | История просмотров |
| `Ctrl + U` | Исходный код страницы |
| `F12` / `Ctrl + Shift + I` | Инструменты разработчика (WebInspector) |
| `Alt + ←` / `Alt + →` | Назад / Вперёд |
| `F11` | Развернуть / восстановить окно |

## Сборка и запуск

```bash
# Сборка релизной версии
cargo build --release

# Запуск браузера (автоматически перезапускает старый процесс при обновлении бинарника)
cargo run --release

# Запуск модульных тестов
cargo test
```
